This template is for authoring exams to conform to the formatting guidelines at the Queensland University of Technology. I am actively using this template, so if you find any issues, please raise them here or send me an email directly. 

Please note that you need to compile using XeLaTeX or LuaLaTeX, *not* PDFLaTeX, which is the default in many systems.

I am indebted to the original author of this template from many years ago, but I cannot find the original source anymore after many years. If this is an extension of your template, please reach out an let me know so that I may credit you here.
